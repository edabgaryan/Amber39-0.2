# AMBER 39 — frontend prototype

Многостраничный HTML/CSS/vanilla JS сайт. 112 **синтетических** участков в `data/plots.json`. Все цены, кадастровые номера и юридические статусы вымышлены. Заявление о 10 000 участков — целевой продуктовый оффер, а не реально загруженная база.

## Запуск

```bash
cd amber39
python -m http.server 8000
```

Открыть http://localhost:8000. Альтернатива: `npm run dev` (нужен Node.js). При открытии HTML двойным кликом браузер обычно блокирует fetch локального JSON — используйте сервер. Карта и шрифты требуют подключения к интернету.
